SAP FUEL & PROCUREMENT SAMPLE DATA
====================================
File: sap_fuel_export_2024_q1.csv

Field origin notes:
  MANDT  - SAP client number (always filtered to tenant's client, typically 100/200/300)
  WERKS  - Plant code from T001W table (4-char, numeric for ECC; alphanumeric for S4)
  MATNR  - 18-char material number, right-padded with spaces (stripped here for readability)
  MAKTX  - Material description from MAKT table (language-dependent, EN assumed)
  MENGE  - Quantity in base UOM from MSEG/MKPF tables
  MEINS  - SAP internal unit of measure code (not ISO - see mapping)
  BUDAT  - Posting date from MKPF, format YYYYMMDD (not ISO 8601)
  BLDAT  - Document date (date on the physical document, may differ from BUDAT)
  BWART  - Movement type from T156 table (261=goods issue, 262=reversal, 201=cost center issue)
  KOSTL  - Cost center from CSKS table
  BUKRS  - Company code from T001 table
  WAERS  - Currency from T001 table
  DMBTR  - Amount in local currency from MSEG table
  EBELN  - Purchase order number
  EBELP  - PO line item (5-digit, zero-padded)
  LIFNR  - Vendor account number from LFA1 table
  NAME1  - Vendor name (from LFA1, may require separate join)
